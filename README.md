# EcoVision AI

An AI-powered smart waste segregation and recycling assistant. EcoVision AI uses computer vision and machine learning to classify waste from a photo and suggest the correct way to dispose of it.

**Live website:** https://niharikabeep.github.io/EcoVision-AI/


## Overview

Improper waste segregation is a major challenge for households and recycling facilities. EcoVision AI helps users identify the type of waste they are holding and tells them how to dispose of it.

Supported waste categories:

- Plastic
- Paper
- Glass
- Metal
- Organic
- E-waste

## Features

- Image-based waste classification using computer vision and ML
- Disposal suggestions for each detected waste category
- Simple web interface accessible from any browser
